\# Login \& Registration System using Python Tkinter



\## Project Overview



This project is a desktop-based Login and Registration System built using \*\*Python\*\* and \*\*Tkinter\*\*. It allows users to create an account, log in with their registered credentials, and access a personalized welcome screen after successful authentication.



The application demonstrates GUI development, file handling, input validation, and basic user authentication using a simple local data storage approach.



\## Features



\* User Registration

\* Login Authentication

\* Password Confirmation Validation

\* Email Validation

\* Phone Number Validation

\* Duplicate Username Detection

\* Duplicate Email Detection

\* Show/Hide Password Option

\* Personalized Welcome Screen

\* Logout Functionality

\* Local File-Based User Data Storage



\## Technologies Used



\* Python

\* Tkinter

\* Pillow (PIL)

\* File Handling

```bash

```

```bash
